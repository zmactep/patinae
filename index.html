Commands & Python

Select residues. Change a representation. Save the scene.

Select residues within 5 Å of a zinc ion.

This example selects the first zinc ion by element and displays its neighbourhood as sticks. The commands can also be run from a .pml script.

Download the example structure ↓
1GVF / zinc-environment.pmlCommand language
# Open the supplied structure
load 1GVF.pdb
as cartoon
color chain

# Inspect the zinc neighbourhood
select metal, first elem Zn
select site, byres near_to 5 of metal
hide everything
show sticks, site
show spheres, metal
set stick_color, atomic, site
zoom site, buffer=3

Interfaces and file formats

Desktop, Python and web interfaces share the molecular data and rendering libraries.

Desktop & browser
A native desktop application and a WebGPU viewer that can be embedded in a web page, including this one.
Commands & Python
PyMOL-style selections, .pml scripts and a Python cmd.* interface for repeatable workflows.
Files & sessions
PDB, mmCIF, bCIF, MOL2, SDF, XYZ and GRO. Native .prs sessions and import of PyMOL .pse files.
Rust & plugins
Separate libraries for molecular data, file reading, selections and rendering. Native plugins and IPC for extensions.

A word about origins

Warren Lyford DeLano 1972–2009

Patinae exists because Warren DeLano created PyMOL — and made it open-source at a time when publication-quality molecular visualization was largely limited to expensive commercial tools. That decision gave an entire generation of structural biologists a tool they could freely use, modify, and learn from. This project carries that spirit forward: a modern codebase, open by default, built with respect for the working scientist. We owe a great deal to his work.
